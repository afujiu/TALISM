# TALISM Chrome 拡張機能

Chrome Manifest V3 の拡張機能です。現在開いているタブから同一オリジンのリンクを巡回できます。

## ローカルで読み込む

1. Chromeで `chrome://extensions/` を開く
2. 右上の「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選択
4. このフォルダーを選択する

## ファイル構成

- `manifest.json` - 拡張機能の設定
- `popup/` - ツールバーから開くポップアップ
- `options/` - 設定ページ
- `background/` - Manifest V3のサービスワーカー

## リンク巡回

1. 巡回を開始するページを開く
2. 拡張機能アイコンを押して「巡回開始」を選択
3. 開始ページと同じドメイン・ポート・スキーム内のリンクを幅優先で巡回
4. 「巡回停止」または設定した最大ページ数に達すると終了

巡回ページ数と移動間隔は「設定を開く」から変更できます。
